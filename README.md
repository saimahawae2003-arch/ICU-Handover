# ICU Smart Handover & SBAR System — Release Package

## ไฟล์ในแพ็กเกจนี้
- `ICU_dev8.html` — ไฟล์แอปหลัก (เปิดใช้งานได้ทันที ไม่ต้องติดตั้งอะไรเพิ่ม)
- `sw.js` — Service Worker แก้ปัญหาแคช/ไฟล์เวอร์ชันเก่าค้าง (ต้องวางไว้ "โฟลเดอร์เดียวกัน" กับไฟล์ HTML)

## วิธีอัปขึ้น GitHub Pages
1. อัปโหลดทั้ง 2 ไฟล์ (`ICU_dev8.html` และ `sw.js`) ไว้ "ระดับเดียวกัน" ในโฟลเดอร์เดียวกันของ repo
2. ถ้าต้องการให้เป็นหน้าแรกของเว็บ (root URL) ให้เปลี่ยนชื่อ `ICU_dev8.html` เป็น `index.html`
   (ไม่บังคับ — ถ้าไม่เปลี่ยนก็เข้าผ่าน URL `.../ICU_dev8.html` ได้ปกติ)
3. เปิด Settings → Pages → เลือก branch ที่อัปโหลดไฟล์ไว้ แล้วรอ deploy เสร็จ

## เกี่ยวกับการแก้ปัญหาแคช (Cache) — เวอร์ชันนี้ไม่ต้องทำอะไรเพิ่มเลย
- `sw.js` ทำงานแบบ **Network-first**: ทุกครั้งที่ผู้ใช้เปิดแอป (ตอนออนไลน์) จะโหลดเนื้อหาล่าสุดจาก
  เซิร์ฟเวอร์ก่อนเสมอ แล้วเขียนทับของเก่าในแคชด้วย key เดียวกันอัตโนมัติ — ไม่มี "เวอร์ชันเก่าค้าง"
  ให้ต้องคอยเคลียร์เอง
- จะดึงจากแคชก็ต่อเมื่อออฟไลน์/เน็ตหลุดเท่านั้น (กันแอปใช้งานไม่ได้เวลาไม่มีเน็ต)
- **ทุกครั้งที่ deploy เวอร์ชันใหม่ในอนาคต: แก้แค่ `ICU_dev8.html` แล้วอัปขึ้น GitHub ตามปกติได้เลย
  ไม่ต้องแตะ `sw.js` และไม่ต้องจำเลขเวอร์ชันใดๆ ทั้งสิ้น**
- (ไฟล์ `sw.js` จะโดนแก้ก็ต่อเมื่อต้องการเปลี่ยนพฤติกรรมออฟไลน์เองเท่านั้น ซึ่งไม่จำเป็นสำหรับการใช้งานทั่วไป)
